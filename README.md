# Quimotropical SRL — sitio web

Sitio estático para GitHub Pages. Sin dependencias ni paso de compilación.

## Publicar
1. En el repositorio `quimotropicalsrl`, borre los archivos anteriores (`index.html`, `styles.css`, `catalogo1.pdf`, `catalogo2.pdf`, `logo.png`, `*-icon.png`).
2. Suba todo el contenido de esta carpeta a la raíz del repositorio.
3. GitHub Pages lo publica solo en 1–2 minutos.

## Estructura
- `index.html` — página única (barrera, laboratorio, contacto)
- `styles.css` — estilos
- `img/` — fotos en WebP con respaldo JPG, logo e íconos
- `catalogo-servicios-laboratorio.pdf`, `catalogo-barrera-antisargazo.pdf` — catálogos comprimidos
- `video-sargazo.mp4` — video de la barrera
